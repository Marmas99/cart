# Cart - A shopping list CLI
Cart can be used to create a shopping list that is fully customizeble.

# Commands
Cart has everything you need to create your own shopping list.
The commands available to you are:
- Add: Create a new item
- Change: Modify an existing item
- Delete: Remove an item you dont want anymore
- List: See an overview of your whole shopping list
- Search: Search for a specific item and show its content
- Clear: Remove all items from your shopping list

# The Item
Cart stores every item in the same way. Every item has a:
- Title
- Amount: Can be in serveral formats
	- Grams
	- Kilograms
	- Liters
	- Centiliters
	- Numbers
